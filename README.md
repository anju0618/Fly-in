# Fly_in
この課題は、最適な移動ルートで複数のドローンをゴールに到達させるシミュレーションプログラムを作るもの

## Description
### Parser
・テキスト形式のマップファイルを読み込み、プログラムで扱えるデータ構造に変換する。（エラー弾く）
### Pathfinding & Scheduliong
・最短経路を見つけるだけでなく、「Aがここにいるから、Bは１ターン待機」などの時間軸を含めた計画を組み立てるロジックを組む
### Simulation Runner
・アルゴリズムをもとに、１ターンずつドローンを動かすシステム

・max_dronesやmax_link_capacity,restrictedの移動ルールが守られてるかを判定
